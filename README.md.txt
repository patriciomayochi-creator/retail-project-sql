Proyecto SQL - Sistema de Ventas Retail

Descripción
Base de datos relacional desarrollada en PostgreSQL para gestionar clientes, productos y ventas de un comercio minorista.

Estructura
El proyecto contiene tres tablas relacionadas mediante claves primarias y foráneas:

- Clientes: información de los compradores.
- Productos: catálogo de artículos, precios y stock.
- Ventas: registro de operaciones comerciales.

Operaciones realizadas
- `CREATE TABLE`: creación de tablas.
- `INSERT INTO`: carga de registros.
- `SELECT`: consultas de datos.
- `UPDATE`: actualización de precios.
- `DELETE`: eliminación de registros.

Tecnologías
PostgreSQL 18 y pgAdmin 4.

Ejecución
Crear una base de datos vacía llamada `retail_project` y ejecutar el archivo `retail_project.sql` desde pgAdmin 4.
